# OS core services

Not yet implemented (M0). Will hold the shell/notification-bar, settings
shade, WiFi management, BLE Companion transport, battery monitoring, clock
(NTP/TZ), and the app launcher/discovery logic — ported out of
CYD-Voice-Recorder's `src/cyd/main.cpp` and formalized into standalone
modules rather than one large file.

See "OS core services vs. built-in apps" and milestone M0 in
`CYDEOS Spec.md` at the repo root.
